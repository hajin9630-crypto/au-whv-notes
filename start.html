정착 시작

도착 후 실제로 세팅할 것들을 주제별로 모았습니다 — 휴대폰·은행·해외송금·앱·구직·돈·택스리펀. 필요할 때 해당 탭만 열어 보세요.

출국 전 준비와 도착 첫 주 순서는 「정착 일정」에 따로 정리했습니다.

호주 휴대폰 · 유심

통신비를 매달 $12~15로 줄이고, 한국·호주 번호를 어떻게 유지할지 정리했습니다.

⭐ 내 조합 — 아이폰 15 Pro 한 대

이대로 진행

한국 번호 → eSIM 유지 · 호주 번호 → 현지 물리 유심. 마트(울월스·콜스) 할인 유심이 대부분 실물 유심이라, 싼 유심 볼 때마다 물리 슬롯에 갈아끼우기가 편해서 이 조합이 최적. 한 폰으로 한국 인증문자·카톡·은행 + 호주 전화·데이터 다 됨.

출국 전 (한국에서)

  • 현재 통신사에 "아이폰 15 Pro, 한국 번호를 eSIM으로 변경하고 싶다" 요청 — SKT·KT·U+·알뜰폰마다 가능 여부·수수료 다름(알뜰폰은 eSIM 미지원도 있으니 꼭 확인)
  • 한국 통신사의 해외 문자 수신·로밍 조건도 출국 전 확인
  • eSIM 변경 후 설정 → 셀룰러에서 한국 회선 이름을 "한국 번호"로 변경(덜 헷갈림)

호주 도착 후 (아이폰 설정)

  • 호주 유심 꽂으면 회선 이름 지정: 한국 eSIM → 한국, 호주 유심 → 호주
  • 셀룰러 데이터 → 호주 (설정 → 셀룰러 → 셀룰러 데이터 → 호주)
  • 한국 회선 데이터 로밍 → 끔 (설정 → 셀룰러 → 한국 → 데이터 로밍 OFF)
  • ⚠️ 셀룰러 데이터 전환 허용 → 끔 — 이걸 꺼야 호주 회선이 잠깐 끊길 때 한국 로밍 데이터를 몰래 쓰는 요금 폭탄을 막음
  • 통화·문자 기본 회선은 필요에 따라 설정

내가 살 호주 유심

  • 도시(시드니·멜번·브리즈번) — 울월스·콜스 할인 중인 Vodafone / Optus 중 싼 것
  • 농장·시골·아웃백 갈 땐 — Boost · ALDI · Telstra(커버리지 우선, Telstra는 선불 eSIM도 있으나 비쌈)
대안(갈아끼우기 귀찮을 때) — 한국=물리 유심 유지 + 호주=eSIM(Telstra 선불 eSIM 등). 대신 마트 초특가 실물 유심을 매달 바꿔 쓰기엔 덜 유리.
핵심만. ① Woolworths·Coles에서 할인 프리페이드 유심($35 → $12~15) 구매 ② 할인은 첫 달만이라 매달 새 유심으로 교체 ③ 번호는 Bring my number from another provider로 유지 ④ Auto Recharge는 반드시 OFF ⑤ 한국 번호는 해지 말고 알뜰폰으로 유지.

1. 유심 싸게 쓰기

호주 프리페이드는 보통 월 $35인데, 마트 할인 유심을 사면 첫 달 $12~15에 씁니다.

정가약 $35
할인가약 $12~15
데이터40GB + 보너스 20GB = 60GB
통화·문자호주 내 무제한
할인은 첫 달만. 그대로 두면 다음 달 자동충전으로 정상가 $35~40이 결제됩니다. 그래서 매달 새 할인 유심으로 교체하는 방식 — 월 $15~20씩, 1년 약 $240 절약.

2. 번호 유지하며 매달 교체

유심을 바꿔도 기존 번호는 유지됩니다. 두 가지 방법:

A. 같은 통신사 유지B. 통신사 번갈아 (추천)
예옵터스 → 옵터스옵터스 ↔ 보다폰 (달마다)
절차고객센터 전화·매장 방문(여권)온라인 번호이동(보다폰 약 5분)
데이터 이월가능한 경우 있음불가
단점연결 오래, 옵터스 3회 제한 사례매달 유심 직접 교체
추천은 B. 통신사가 달라지면 온라인으로 번호이동이 되어 고객센터에 전화할 필요가 없습니다. 할인할 때 유심을 여러 장 사두고 한 달씩 번갈아 쓰세요.

3. 온라인 개통 순서 (보다폰 예시)

  • ① 보다폰 개통 사이트 접속
  • ② 유심의 Activation Key / 시리얼 번호 입력
  • ③ "웹사이트에서 구매했나요?" → No
  • ④ 기기 종류 → Phone
  • ⑤ 이름·생년월일·주소·이메일 입력
  • ⑥ 신분증 → Passport
  • ⑦ 번호 유지 → Bring my number from another provider (⚠️ 새 번호 발급 아님)
  • ⑧ 기존 호주 번호 입력 → 기존 통신사 선택(예: Optus)
  • ⑨ 계정 유형 → Prepaid · 비밀번호 설정
  • ⑩ 카드 정보 입력 → Auto Recharge 는 반드시 No
  • ⑪ Activate Now → 완료되면 새 유심 장착 후 재부팅
같은 통신사(A방식)라면 매장 방문·고객센터 전화로 "새 프리페이드 유심으로 기존 번호를 옮기고 싶다"고 요청. 문자 인증(예: 1510으로 PROCEED 답장) 후 15분~4시간 내 활성화, 기존 유심에 SOS가 뜨면 새 유심으로 교체.

4. ⚠️ 자동결제는 반드시 끄기

Auto Recharge / Auto Top-up / Automatic Payment 를 모두 OFF. 개통 때 카드를 넣는 건 다음 달 자동충전 때문입니다. 안 끄면 이미 다른 통신사를 쓰고 있는데도 정상가 $40이 자동 결제됩니다(고객센터로 환불은 받았지만 처음부터 끄는 게 최선).

6. 데이터는 얼마나?

워홀 일반 생활엔 월 45~60GB면 충분합니다(유튜브·SNS·지도·카톡·검색·핫스팟 일부). 많이 쓰는 편인데도 매달 약 20GB가 남았다는 후기.

단, 노트북 핫스팟으로 넷플릭스·영상을 자주 보거나 숙소에 와이파이가 없으면 더 큰 용량이 필요합니다.

7. 한국 번호 — 해지하지 마세요

해지·장기정지 대신 저렴한 알뜰폰 요금제로 유지하세요. 해외에서도 한국 번호로 본인 인증할 일이 계속 생깁니다.

  • 은행·카드 인증 · 공동인증서 재등록 · 비밀번호 찾기
  • 쇼핑몰·카카오톡·각종 계정 문자 인증
한국 번호를 없애면 해외에서 본인 인증이 막힐 수 있어요. 최소 요금제로라도 유지가 안전합니다. (출국 전 준비는 「정착 일정」 → 출국 전의 한국 폰 요금제 참고.)

단점 2대 관리·분실 위험. 한국폰은 인증 문자 올 때만 켬(평소 캐리어 보관).

한국=eSIM · 호주=물리 유심
짐 최소

장점 한 대로 한국 문자·호주 번호 동시 확인, 짐 적음.

단점 eSIM 지원 기종만(갤럭시 일부 미지원 — 출국 전 확인), 배터리↑, 데이터 회선 잘못 설정 시 한국 유심 로밍요금, 분실 시 두 번호 동시 상실.

eSIM 듀얼심이면 모바일 데이터 기본 회선은 호주 유심으로, 한국 회선 데이터 로밍은 꺼두세요.

9. 도착 직후 인터넷

공항 도착 직후엔 현지 유심이 없어 지도·교통 앱이 어렵습니다. 대비법:

  • 구글 지도 오프라인 저장 — 출국 전 공항~숙소 지역을 미리 저장
  • 경로 미리 캡처 — 버스 번호·정류장·숙소 주소 메모
  • 공항 유심 — 바로 되지만 할인 폭 작고 장기 요금 권유 → 비추천
  • 한국에서 여행용 eSIM — 3일짜리 호주 eSIM 약 6,500원, 도착 즉시 활성화 → 숙소 도착 후 Woolworths·Coles 할인 유심으로 교체
물리 유심은 배송·유심핀 필요, eSIM은 QR로 즉시 등록(기기 지원 필요). 마트 유심엔 유심핀이 없는 경우가 많으니 유심핀은 한국에서 챙겨가세요.

11. 국제전화 · 안 터지는 곳

한국으로 전화

+82 + 한국번호 맨 앞 0 뺀 번호. 예: 010-1234-5678 → +82-10-1234-5678.

상대에겐 낯선 호주 번호로 떠서 스팸 오해를 받을 수 있어요. 실제로는 카톡 보이스톡 · WhatsApp · FaceTime · 인스타 통화가 편합니다.

데이터 안 터지는 상황

  • 인파 많은 곳(축제·드론쇼·공연·에어쇼) — 통신사 불문 느려지거나 끊김

택스리펀 (Tax Return)

호주도 매년 세금 신고를 하고, 워홀러는 과다 원천징수분·메디케어 레비를 돌려받을 수 있어요.

순서가 중요. 워홀·학생비자면 택스리펀 전에 MES(메디케어 레비 면제)를 먼저 신청하세요. 그냥 택스리펀만 하면 안 내도 될 레비까지 놓치는 사람이 많아요.

1. MES — 메디케어 레비 면제 (먼저!)

MES(Medicare Entitlement Statement) = "이 기간 동안 호주 메디케어를 이용할 수 없었다"는 증명서. 워홀러는 메디케어 대상이 아니라 레비(2%)를 안 내도 되는데, 급여에서 이미 떼였다면 MES로 면제·환급받습니다.

한국은 상호 의료협정국이 아닙니다 → 한국 워홀러는 면제 대상입니다. (영국·아일랜드·이탈리아 등 협정국은 세법상 거주자면 낼 수도 있음.)

신청 순서 (온라인)

  • myGov 로그인 → View and link services → IHI(Individual Healthcare Identifiers) 연결(처음이면 "I need an IHI")
  • 여권 또는 호주 운전면허로 본인 인증 → 개인정보·연락처·호주 주소·여권 정보 입력
  • Go to MES dashboard → Apply for a MES → Get started
  • 신청 회계연도 선택(예: 2025.7~2026.6) → 여권 정보 → 수령 방법(온라인=myGov Inbox가 더 빠름 / 실물=우편)
  • 거주 이력·타국 건강보험·영주권 신청 여부 질문에 답 → 제출(Submit)
별도 서류 제출은 대개 필요 없고, 심사 며칠~약 3주 후 승인되면 이메일로 결과가 옵니다. MES dashboard에서 진행 상황 확인. MES는 회계연도 끝난 뒤(7월~) 신청합니다.
